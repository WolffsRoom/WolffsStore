# Wolff's Store v1.1.4 — Official Poll results

## Fixes
- The finished community poll is explicitly marked closed by the official synced catalog. The Vita no longer shows a misleading “Results in 1 day” message if its local system clock is incorrect.
- The poll page displays the verified winner and results. Confirmed counts are bundled and cached, so results are available offline.
- The **Poll Result** news article includes the same centered **pixel-art bar chart** as the website, drawn natively by vita2d, in both Portuguese and English.
- **Votação Encerrada!** is now the Portuguese announcement wording; update text uses singular **vou** instead of **vamos**, as Wolff's Room is a one-person project.
- Original poll counts: 16 for New Browser for Vita, 1 each for Reddit Vita, Internet Archive Vita and GameFAQs Vita.

## Installation
Install the new WolffsStore.vpk over the existing app with VitaShell or the built-in updater.
Title IDs remain WFFS00042 (app) and WFFS00043 (updater).

## Validation
Automated tests and VitaSDK compilation performed. Hardware confirmation is recommended.
